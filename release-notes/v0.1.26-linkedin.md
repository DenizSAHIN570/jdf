# JDF 0.1.26 — what's new (plain-language notes for LinkedIn)

_Suggested post below. The detailed, developer-facing list lives in `CHANGELOG.md`._

---

**JDF 0.1.26 is out — and it's mostly about trust.**

JDF is a document format that keeps your document as readable JSON instead of a binary PDF: you can diff it, search it, feed it to an AI pipeline, and still print it. Version 0.1.26 fixes the rough edges people hit first, and makes PDF import handle a lot more of the PDFs out in the wild.

**If you install with Homebrew on a Mac:** the "Apple could not verify this app" / "Move to Trash" dialog is gone. The installer image itself is now notarized by Apple, not just the app inside it.

**Opening files just works now.** Recent Files, double-clicking in Finder, or dropping a file from any folder used to fail unless the file lived in Downloads, Documents or Desktop. That restriction is gone.

**Editing is safe again.** Editing a document with images no longer strips the images on save. Bold, italic and links show up exactly as they do on the web. Undo, keyboard shortcuts and the JSON view behave the way you'd expect.

**PDF import got a lot smarter.** The importer now understands:
- logos, headers and other nested artwork placed via PDF "forms" — they land where they belong
- the right colour for every word, even in PDFs where text is split into fragments
- inline images, stencil graphics, repeated images and gradient fills
- bookmarks (they become real headings and a table of contents), internal "see page 12" links, author/date metadata
- password-protected PDFs
- scanned PDFs: the invisible OCR text is kept, so the document stays searchable

All of this is shared between the desktop app and the command-line tool, so a PDF converted in CI looks exactly like the one you open on your Mac.

Download: https://github.com/uurtech/jdf/releases/tag/v0.1.26
Mac: `brew install --cask uurtech/jdf/jdf` · CLI: `npx @uurtech/jdf-cli convert file.pdf`
